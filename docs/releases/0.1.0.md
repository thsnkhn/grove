# Grove 0.1.0

First public development release of Grove.

## Included

- Native macOS menu bar app.
- Local MCP server for Apple Calendar and Reminders.
- Calendar event tools for reading and editing events.
- Reminders tools for reading, creating, completing, and deleting reminders.
- Local-first operation with no account, cloud service, or database.
- Sparkle update support.

Grove requires macOS 14 or later. Calendar and Reminders access is requested
when you enable each integration.
